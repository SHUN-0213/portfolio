# SHUN TANAKA - Portfolio

Web Developer / Web Creator のポートフォリオサイトです。

Webサイト制作やWebシステム開発の制作実績、スキル、保有資格などを掲載しています。

## Overview

本サイトは、Web制作・Web開発の副業活動に向けて制作しています。

「シンプルで見やすい」をコンセプトに、PC・タブレット・スマートフォンの
各デバイスで快適に閲覧できるレスポンシブデザインを採用しています。

## Features

- レスポンシブデザイン
- ハンバーガーメニュー
- 制作実績の掲載
- スキル・資格の掲載
- SNS / GitHubへのリンク
- お問い合わせフォーム
- シンプルでモダンなUI

## Tech Stack

- HTML
- CSS
- JavaScript
- Noto Sans JP
